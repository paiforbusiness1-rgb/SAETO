# Guion — Consumibles (láminas)

**Objetivo:** mostrar outputs visibles tipo presentación (mapa + gráfica + cruce).

## Arranque

1. Backend: `uvicorn main:app --reload --port 8001` desde `backend/`
2. Frontend: `npm run dev` en `frontend/`
3. Abrir http://127.0.0.1:5173

## Recorrido (~8 min)

1. Menú **Consumibles** (o Inteligencia → Consumibles).  
2. Abrir **Calor temático · Agua** → señalar focos en mapa y barras.  
3. Abrir **Calor temático · Selector** → cambiar a Basura / Alumbrado / Seguridad.  
4. Abrir **Cruce electoral × problemática** → lectura en mapa y gráfica.  
5. Abrir **Constructo** → historia completa + recomendaciones.  
6. Cierre: el mismo formato sirve cuando carguen su información operativa.
